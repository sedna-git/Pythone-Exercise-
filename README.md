# 🐍 Python Practical Exercises

## 📌 About This Repository

This repository contains a collection of important and practical Python exercises designed to improve programming skills and strengthen knowledge of Python fundamentals.

It includes various examples, useful commands, and practical coding challenges covering different Python concepts.

## 📂 Repository Structure

The exercises are uploaded in two different formats:

- **`.py` Files:** Individual Python exercises that can be downloaded and executed separately.
- **`.rar` Files:** Compressed collections of multiple Python exercises. These files must be extracted before accessing and running the Python scripts.

## 🚀 How to Use

1. Clone or download this repository.
2. If you download a `.py` file, open and run it using Python.
3. If you download a `.rar` file, extract it using WinRAR or 7-Zip.
4. Open the extracted folder and run the desired Python files.

## 🛠️ Requirements

- Python 3.x
